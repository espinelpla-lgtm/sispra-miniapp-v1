# SISPRA · Miniapp de reportes

Miniapp de Telegram para elaborar reportes de patrullajes y recorridos. Se abre desde el bot con `/reporte_sispra` y envía los datos a Apps Script (SISPRA).

- `index.html`: la miniapp completa (sin compilación).
- `vercel.json`: encabezados de caché.

Versión vigente: V7.8.63 (botón opcional «Revisar redacción», que funciona con el interruptor `MINIAPP_CORRECCION_IA_ACTIVA` de Apps Script).

Cada cambio en `main` se publica automáticamente en Vercel.
